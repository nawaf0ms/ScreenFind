# ScreenFind

> © 2026 **[nawaf0ms](https://github.com/nawaf0ms)** — رخصة MIT (انظر [LICENSE](LICENSE)).

يُتيح لك هذا التطبيق البحث عن أي نص داخل أي محتوى معروض على شاشتك، حتى وإن كان هذا المحتوى لا يدعم البحث بطبيعته، مثل ملفات PDF الممسوحة ضوئياً، الكتب المصوّرة، برامج العرض المحمية، جلسات سطح المكتب البعيد (Remote Desktop)، أو التطبيقات القديمة التي لا تستجيب لاختصار البحث المعتاد `Ctrl+F`.

**كيف يعمل؟**
بمجرد الضغط على الاختصار **Ctrl+Shift+F**، سيظهر لك صندوق بحث عائم. يقرأ التطبيق بذكاء النافذة التي كنت تنظر إليها (معتمداً على تقنية واجهة أتمتة المستخدم UI Automation أولاً، ثم تقنية التعرف البصري على الحروف OCR إن لزم الأمر)، ليقوم بتظليل نتائج البحث وتحديدها مباشرة فوق الشاشة.

ما يُميز التطبيق أنه يُعطي **اللغتين العربية والإنجليزية نفس القدر من الأهمية**، كما أنه مصمم ليعمل **دون الحاجة لأي اتصال بالإنترنت (أوفلاين بالكامل)**، مما يضمن خصوصية بياناتك.

## المتطلبات الأساسية

| المكوّن | المتطلبات |
|---|---|
| **نظام التشغيل** | نظام Windows 10 (الإصدار 19041) أو أحدث. |
| **للبناء والتطوير** | .NET 8 SDK (التشغيل النهائي مستقل ولا يحتاج لمتطلبات مسبقة). |
| **لغات التعرف البصري (OCR)** | يجب أن تكون حزمتا اللغتين العربية والإنجليزية مثبتتين في نظام ويندوز لديك. |

للتحقق من لغات OCR المثبّتة في جهازك، يمكنك تشغيل الأمر التالي:
```bash
dotnet run --project ScreenFind.Feasibility -- langs
```

إذا لم تكن اللغة العربية مثبتة، يمكنك إضافتها عبر مسار إعدادات ويندوز التالي:
`Settings → Time & Language → Language & region → العربية → Options → Basic typing / OCR`

## خطوات التثبيت

**الطريقة الأسهل — نسخة جاهزة:** نزّل ملف `ScreenFind-1.0.0.msi` من
[صفحة الإصدارات](https://github.com/nawaf0ms/ScreenFind/releases/latest) وشغّله مباشرة، دون
الحاجة لصلاحيات المسؤول ولا لتثبيت .NET مسبقاً.

### البناء من المصدر

إن أردت بناء المُثبِّت بنفسك، استخدم الأمر التالي في سطر الأوامر:
```bash
powershell -ExecutionPolicy Bypass -File build\build-installer.ps1
```

سيقوم هذا الأمر بإنتاج ملف التثبيت `dist\ScreenFind-1.0.0.msi` المُخصص **لكل مستخدم** بشكل مستقل، وبدون الحاجة لصلاحيات المسؤول (Administrator). سيُثبت البرنامج في المسار `%LOCALAPPDATA%\Programs\ScreenFind`، وسيُنشئ اختصاراً في قائمة "ابدأ"، ليعمل تلقائياً فور انتهاء التثبيت.

أثناء التثبيت، ستُعرض لك شاشة لاختيار **لغة الواجهة** (العربية أو الإنجليزية). سيُحفظ خيارك في سجل النظام (`HKCU\Software\ScreenFind\Language`) ليُستخدم في التشغيل الأول فقط، وبعد ذلك سيصبح ملف الإعدادات الخاص بالبرنامج هو المرجع الأساسي للغة.

لتشغيل ملف التثبيت:
```bash
msiexec /i dist\ScreenFind-1.0.0.msi
```

*   **للتثبيت الصامت بلغة محددة:** `msiexec /i ScreenFind-1.0.0.msi UILANG=en /qb`
*   **لإلغاء التثبيت:** `msiexec /x dist\ScreenFind-1.0.0.msi`، أو يمكنك حذفه بالطريقة المعتادة من قائمة "التطبيقات المثبّتة" في ويندوز.

> **ملاحظة للمطورين:** بناء ملف المُثبِّت يتطلب تثبيت الأداة `wix` (النسخة 5.0.2 تحديداً، لأنها مجانية، بينما تشترط النسخ الأحدث قبول اتفاقية OSMF):
> `dotnet tool install --global wix --version 5.0.2`

## البناء والتشغيل من المصدر

لبناء المشروع:
```bash
dotnet build ScreenFind.sln
```

للتشغيل:
```bash
dotnet run --project ScreenFind.App
```

> **تنبيه:** التطبيق مصمم ليعمل في الخلفية بلا نافذة رئيسية. عند تشغيله، سيظهر لك إشعار يوضح أنه "جاهز"، وستجد أيقونة العدسة في شريط نظام ويندوز (بجوار الساعة). (في ويندوز 11، قد تُخفى الأيقونة داخل القائمة المطوية؛ يُفضل سحبها وتثبيتها في الشريط لتسهيل الوصول إليها).
> 
> في أول تشغيل للتطبيق، ستُفتح شاشة الإعدادات تلقائياً. وإذا حاولت تشغيل نسخة ثانية من التطبيق بينما الأولى تعمل، فلن تُفتح نافذة جديدة؛ بل ستُوجّه النسخة العاملة لإظهار صندوق البحث، ثم تُغلق النسخة الثانية نفسها لتجنب التكرار.

### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+Shift+F` | إظهار أو إخفاء صندوق البحث. |
| `Enter` أو `F3` | الانتقال إلى النتيجة التالية. |
| `Shift+Enter` | العودة إلى النتيجة السابقة. |
| `Ctrl+C` | نسخ النص المستخرج بالكامل إلى الحافظة (Clipboard). |
| `Esc` | إغلاق صندوق البحث والعودة للتركيز على النافذة الأصلية. |

تحتوي قائمة أيقونة شريط النظام على الخيارات التالية: **بحث في الشاشة**، **الإعدادات...**، و**إنهاء**.

### استخراج حزمة تنفيذية واحدة (بدون مُثبِّت)

إذا كنت تفضل استخدام البرنامج كملف تنفيذي مستقل:
```bash
dotnet publish ScreenFind.App -c Release
```
ستجد الملف المستقل في المسار التالي:
`ScreenFind.App\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish`

## الإعدادات

يمكنك الوصول إلى شاشة الإعدادات عبر أيقونة شريط النظام. تُحفظ هذه الإعدادات في المسار `%APPDATA%\ScreenFind\settings.json`، وتُطبَّق تغييراتها فوراً دون الحاجة لإعادة تشغيل التطبيق:

| الفئة | الإعدادات المتاحة للضبط |
|---|---|
| **اللغة** | الاختيار بين (عربي / English / أو حسب لغة ويندوز) — ويتم تطبيقها وتعديل اتجاه الواجهة فوراً. |
| **الاختصار العام** | تخصيص زر البحث بأي تركيبة مفاتيح تحتوي على مُعدِّل (Modifier) واحد على الأقل، ويُعاد تسجيل الاختصار فور حفظه. |
| **الاستخراج** | التحكم بتفعيل طبقة UI Automation، تحديد لغات OCR، تغيير معامل التكبير، طريقة إعادة التحجيم، وتفعيل وضع التدرّج الرمادي. |
| **المطابقة** | تفعيل المطابقة الضبابية (للأخطاء الإملائية الطفيفة)، تحديد أدنى نسبة تشابه مقبولة (0.60–1.00)، والحد الأقصى لعدد النتائج المعروضة. |
| **ألوان التظليل** | تخصيص لون جميع النتائج، لون النتيجة النشطة، ولون إطارها باستخدام كود الألوان `#AARRGGBB`. |
| **السلوك** | ضبط مهلة البحث التلقائي أثناء الكتابة، وتفعيل التشغيل التلقائي مع بدء النظام (يتعدل مفتاح `HKCU\...\Run` فقط). |

> **ملاحظة:** تغيير أي من إعدادات الاستخراج سيؤدي إلى مسح النص المخزَّن حالياً، وسيجبر التطبيق على إعادة قراءة الشاشة من جديد في عملية البحث التالية.

## بنية الحل والتنظيم البرمجي (Architecture)

قُسّم المشروع إلى عدة أقسام لتنظيم العمل وسهولة الصيانة:

*   **`ScreenFind.Core`**: القلب النابض للتطبيق، وهو مستقل تماماً عن واجهة المستخدم (WPF)، مما يجعله قابلاً للاختبار البرمجي بسهولة. يحتوي على أدوات التقاط الشاشة، ومحركات الاستخراج (OCR و UIA)، وأدوات مطابقة النصوص وإدارة الإعدادات.
*   **`ScreenFind.App`**: طبقة واجهة المستخدم المبنية بتقنية WPF. تشمل نوافذ البحث العائمة، شاشة الإعدادات، شريط النظام، وإدارة تشغيل نسخة واحدة من التطبيق.
*   **`ScreenFind.Cli`**: أداة موجه أوامر (Console) لطباعة الكلمات المستخرَجة وإحداثياتها للمساعدة في فحص أداء النظام.
*   **`ScreenFind.Feasibility`**: أداة مخصصة لقياس دقة تقنية OCR وتوليد عينات اختبار متدهورة الجودة لدراسة كفاءة النظام.
*   **`ScreenFind.Tests`**: يحتوي المشروع على 77 اختباراً للتحقق من أداء مطبّع النصوص، محرك المطابقة، حساب الإحداثيات، واختبارات التكامل.
*   **`build`**: مجلد يحتوي على ملفات بناء المُثبِّت، إعدادات الشاشات عالية الدقة، والأيقونات.

### مسار معالجة البيانات

لفهم كيف يتعامل التطبيق مع طلب البحث عند الضغط على `Ctrl+Shift+F`:
1.  يتم حفظ النافذة النشطة حالياً **قبل** ظهور أي واجهة للمستخدم.
2.  يُمرر الطلب إلى خط المعالجة (`ExtractionPipeline`).
3.  **المستوى الأول:** يحاول قراءة النص بدقة عالية عبر (`UiaTextExtractor`) للحصول على النصوص وإحداثياتها دون الحاجة لالتقاط صورة.
4.  **المستوى الثاني:** إذا فشل المستوى الأول، تُلتقط صورة للشاشة، وتُعالج مسبقاً، ثم يُقرأ النص العربي والإنجليزي بالتوازي عبر (`OcrTextExtractor`)، وتُدمج النتائج معاً.
5.  أخيراً، يُطابق النص المبحوث عنه وتُعرض التظليلات عبر نوافذ شفافة تظهر فوق كل شاشة متصلة بالجهاز.

## أدوات التشخيص

لتشخيص أخطاء الاستخراج وفحص الأداء، يوفر المشروع الأوامر التالية:

*   **لتحليل دقة استخراج التطبيق لنافذة محددة:**
    ```bash
    dotnet run --project ScreenFind.Cli -- --once 4 --search "المكتبة"
    ```
    سيطبع هذا الأمر اسم النافذة المستهدفة، المصدر الذي استُخرج منه النص، الوقت المستغرق، بالإضافة إلى الكلمات مع إحداثياتها الفعلية ونتائج البحث. يمكنك إضافة `--ocr-only` أو `--uia-only` لاختبار طبقة محددة وعزل الطبقة الأخرى.

*   **لتوليد عينات اختبار ودراسة دقة التعرف:**
    ```bash
    dotnet run --project ScreenFind.Feasibility -- gate
    ```
    يقوم هذا الأمر بتوليد صور اصطناعية تحاكي النصوص المطبوعة أو الممسوحة ضوئياً بجودة رديئة (باللغتين العربية والإنجليزية)، ليقيس دقة التعرف عليها ويصدر تقريراً مفصلاً. 
    *(يُفضل تشغيله على جهازك الشخصي، حيث تعتمد النتائج على حزم اللغات المثبتة لديك)*. 

*   **لاختبار محرك التعرف على صورة معينة بشكل مباشر:**
    ```bash
    dotnet run --project ScreenFind.Feasibility -- dump <image.png> ar x2-bicubic
    ```
    وهي أسرع طريقة لطباعة المخرجات الخام لمحرك التعرف ومعرفة أسباب أي خطأ في القراءة.

## أبرز القرارات التقنية التي بُني عليها التطبيق

واجه المشروع عدة تحديات تقنية، وتم حلها من خلال القرارات التالية:

1.  **معالجة النصوص العربية:** يقرأ محرك ويندوز الكلمات بناءً على ترتيبها البصري (من اليسار لليمين)، وهو ما يعكس ترتيب الجمل العربية. ولحل ذلك، أضفنا مُعالج `ReadingOrder` الذي يعيد ترتيب كل سطر منطقياً لضمان نجاح عملية البحث والنسخ.
2.  **الدمج الذكي للمحركات:** يتم دمج نتائج محركي اللغة العربية والإنجليزية على مستوى السطر بدلاً من الكلمة، لأن دمج الكلمات فردياً يُفسد ترتيب القراءة العربي.
3.  **مرونة محرك OCR:** أُنشئت واجهة `IOcrEngine` لتكون نقطة استبدال سهلة في حال أردنا مستقبلاً استخدام محركات أخرى (مثل PaddleOCR أو Tesseract) بأقل جهد برمجي.
4.  **إحداثيات مستقلة:** تم الاعتماد على نظام إحداثيات مخصص `Rect` في النواة لتجنب أي ارتباط بمكتبات واجهة المستخدم (WPF).
5.  **تركيز صندوق البحث:** يستحوذ صندوق البحث على تركيز النظام ليتيح للمستخدم الكتابة مباشرة؛ ولهذا كان من الضروري جداً حفظ النافذة الهدف قبل ظهور الصندوق.
6.  **تجاوز قصور UIA:** تجنبنا الاعتماد على `ValuePattern` في طبقة واجهة الأتمتة لأنه لا يوفر إحداثيات دقيقة للكلمات، وبدون الإحداثيات يصبح تظليل النصوص مستحيلاً.
7.  **تحسين الصور قبل التكبير:** تُحوّل الصور إلى التدرّج الرمادي قبل عملية التكبير لتخفيف استهلاك الموارد البرمجية (تستهلك ربع الجهد)، مع تقليص حجم الصور الضخمة تلقائياً للحفاظ على الأداء. ولا تُحوّل الصور إلى أبيض وأسود صرف (Binarization) لأن ذلك يُضعف دقة محرك ويندوز فعلياً.
8.  **ترجمة مُدمجة:** جُمعت نصوص واجهة التطبيق في قاموس C# برمجي واحد بدلاً من استخدام ملفات متفرقة، ليكون مراجعتها أسهل ولتجنب مشاكل التجميع في النسخة المستقلة (single-file).
9.  **دقة مقاسات النوافذ:** تم ضبط أحجام النوافذ بالبكسل الفعلي عبر واجهات نظام ويندوز البرمجية للتعامل مع الشاشات عالية الدقة (High DPI) وتجنب مشاكل القص والانحراف في تظليل النصوص.
10. **إدارة النسخ المتعددة:** تم تحسين التطبيق ليتعامل مع محاولة فتح نسخة ثانية بذكاء؛ فبدلاً من أن تفشل النسخة الجديدة بصمت، أصبحت تُرسل إشارة للنسخة العاملة لكي تُظهر صندوق البحث للمستخدم، ثم تُغلق النسخة الجديدة نفسها.
11. **نصوص المُثبِّت:** أبقينا لغة ملف المُثبِّت باللغة الإنجليزية لضمان توافق التشفير وعمله بسلاسة على كافة أنظمة التشغيل حول العالم، بينما بقيت واجهة التطبيق نفسه تدعم اللغتين العربية والإنجليزية.

## ما الذي لا يشمله هذا الإصدار (v1)

يركز هذا الإصدار على أداء مهمته الأساسية بكفاءة عالية، وبالتالي فهو **لا يتضمن الميزات التالية**:
*   لا يقوم بالتمرير التلقائي للصفحات (Auto-scroll).
*   لا يمتلك قدرة على فهرسة محتوى المستندات بشكل كامل.
*   لا يقوم باستخراج وتنسيق الجداول، ولا يقدم ميزات للترجمة أو التلخيص.
*   **كما أنه لا يتصل بشبكة الإنترنت إطلاقاً**.
